# Портфолио Системного Аналитика | Технический дизайн

Добро пожаловать! Здесь собраны технические задания и архитектурные решения для FinTech-продуктов.
13 лет опыта в IT (веб-мастер, бэкенд) помогают мне проектировать надежные системы, понимая язык разработчиков и структуры БД.

---

## 📁 Проекты

### 1. 💸 Интеграция с СБП (Мгновенные переводы)
Разработка асинхронного процесса (STP) для микросервисов.
*   **Case Study:** 👉 [**Читать SBP_CASE.md**](SBP_CASE.md)
*   **Ключевые решения:** Блокировки (`SELECT FOR UPDATE`), идемпотентность, устойчивость к сбоям.
*   **Стек:** BPMN, UML, REST/SOAP (ISO 20022), SQL.

### 📊 2. Сервис истории операций (High-Load)
Архитектура высокопроизводительного микросервиса выписок.
*   **Case Study:** 👉 [**Читать HIGH_LOAD_STATEMENTS_CASE.md**](HIGH_LOAD_STATEMENTS_CASE.md)
*   **Ключевые решения:** Паттерн *Database per Service*, партиционирование, кэширование в Redis, оконные функции SQL.
*   **Стек:** High-Load, OpenAPI/Swagger, Redis, SQL.
